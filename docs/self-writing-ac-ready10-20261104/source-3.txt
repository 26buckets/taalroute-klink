KLINK ALFA C TYP DE ZIN 021–040. LEIDENDE TAALREDACTIE v3.0
Vervangt eerdere tekstbron 1.0. Twintig zinnen met twee correct beoordeelde natuurlijke varianten, eigen uitleg bij ieder model en gerichte foutuitleg. Bij 032 en 039 zijn onjuiste komma-constructies met 'daarom' hersteld. De leerling mag andere correcte zinnen schrijven. Status kandidaat/HOLD.


KSW-AC-TZ-021
Situatie: Je hebt een blauwe fiets. Schrijf wat je hebt.
Opdracht: Lees de situatie. Typ één goede zin.
Model A: Ik heb een blauwe fiets.
Waarom goed: Je zegt dat je een blauwe fiets hebt.
Model B: Mijn fiets is blauw.
Waarom goed: Je zegt met andere woorden dat je fiets blauw is.
Foutvoorbeeld: Ik heeft een blauwe fiets.
Waarom fout: Bij ik gebruik je heb, niet heeft.
