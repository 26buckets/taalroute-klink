Klink — vaste luisterplek in het speelvlak

De gemarkeerde plek uit Nico’s screenshot is de concrete bron: linksboven in het speelvlak, onder de titel. De oude plek rechtsboven in de kop is vervangen. De bestaande bediening wordt via dezelfde portal naar de nieuwe doellocatie verplaatst. De knop blijft bij scrollen bereikbaar. Werkbladrijen en het cursistscherm van de docent gebruiken dezelfde kant binnen hun eigen speelvlak.

Alleen vijf JSX-doellocaties en de plaatsingsstijl wijzigen. De functies, tekstinhoud en toestand blijven identiek wanneer de doellocaties uit de vergelijking worden weggelaten. De oorspronkelijke vormgevingsvloer en alle eerdere bron-/audio-/publicatieakkoorden blijven behouden. Geen nieuwe audio, beelden, inhoud, opslag of publicatieconfiguratie. Controle via de bestaande publicatieketen; alle uitgebreide controles lokaal, geen GitHub Actions.
