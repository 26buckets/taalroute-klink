# Onafhankelijke taalreview Klink

Drie aparte AI-reviewers hebben zonder de eerdere reviewconclusies alle 288 vragen en 1152 antwoordkaarten beoordeeld: 96 vragen/384 kaarten per niveau. Eerste rapporten zijn ongewijzigd bewaard. Twaalf directe verbeteringen en één voorzorgsvervanging zijn toegepast; alle dertien gewijzigde vragen zijn door de oorspronkelijke onafhankelijke niveaureviewer opnieuw goedgekeurd op de definitieve bronhash.

Vijf wijzigingen op A1, vier op A2 en vier op B1. Onder meer: natuurlijk vervolg na Ja niet als fout antwoord gebruiken; verdedigbare combinaties bij afspraak en aantekeningen vervangen; hetzelfde tijdstip in andere woorden herhalen; volledige medische vraag; verzoek om een vergunning; expliciete oorzaak en volledig hulpaanbod op woensdag. Ervaring opsteken is uit voorzorg vervangen, zonder claim dat deze formulering onmogelijk is.

Vijftien noodzakelijke ElevenLabs-opnamen, met Roland als instructiestem en Remko/Roos voor doeltaal. Alle 1497 bestaande geregistreerde bestanden blijven behouden. Embedded Taalroute-metadata zijn verliesloos aangebracht; nieuwe spraak is automatisch naar tekst terugvergeleken. Geen menselijke fonetische beluistering geclaimd.

Dit is een onafhankelijke tweede AI-review, geen onafhankelijke menselijke taalkeuring, officiële CEFR-certificering of cursistenpilot. Leerdoelen/lesplankoppelingen uit docs/word-use-20261101/teaching-plan.json blijven gelden. Uiterlijk, routes, opslag en overige inhoud blijven bytegelijk aan de actuele basis. Alle zware controles lokaal; publicatie alleen via canonieke main en npm run deploy.

Zie content-review.json, independent-a1/a2/b1.json, final-a1/a2/b1.json, changes.json, verification.json, publication.json en de gecontroleerde Drive-back-ups.
